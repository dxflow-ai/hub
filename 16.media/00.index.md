Video and audio applications running on remote compute and streamed to your browser. Each builds on the [Void Desktop](/hub/desktop/void) image and opens maximized.

These are the hub's first entries that stream sound as well as picture: `AUDIO` is on by default, so the desktop's PulseAudio sink reaches the browser over port `6100`. Rendering and encoding run on the CPU — no runner carries a card — so give a long timeline more `cpu` rather than expecting a GPU.

This category covers:

- **Kdenlive** — multi-track non-linear video editing
- **Shotcut** — video editing across a wide format range
- **Audacity** — multi-track audio editing and mastering
- **VLC** — playback for nearly every container and codec
