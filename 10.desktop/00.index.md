Remote Linux desktops — full GUI environments streamed to your browser, backed by remote compute. These images (Openbox, a taskbar, a terminal, and a file manager over TurboVNC and noVNC) are also the base that the [browser](/hub/browser), [graphics](/hub/graphics), [messaging](/hub/messaging), [office](/hub/office), [media](/hub/media), [engineering](/hub/engineering), [geospatial](/hub/geospatial), and [utilities](/hub/utilities) apps build on, along with the desktop entries in [development](/hub/development), [analytics](/hub/analytics), [molecular](/hub/molecular), and [genomics](/hub/genomics).

This category covers:

- **Ubuntu** — a familiar, widely supported desktop and the base for GUI apps
- **Fedora** — a leading-edge desktop
- **Void** — a lightweight, independent desktop
